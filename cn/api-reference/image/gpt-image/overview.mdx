GPT Image 系列的六个模型都走 `POST /v1/tasks`，请求地址不随模型变化。它们的动作和请求形状一致，差别集中在画幅与分辨率的取值、专有参数和计费方式三处，选型只改 `model` 字段。

## 如何选择

| 需求 | 推荐模型 | 原因 |
|---|---|---|
| 最高画质，或 `xhigh` / `max` 档位 | `gpt-image-2.5` `gpt-image-2.5-sunburst` | 只有 2.5 有五档画质；同名档位与上一代不通用 |
| 编辑精度优先的成品素材 | `gpt-image-2.5-sunburst` | 与 Flare 同参数同价，取舍偏向精度 |
| `2k` / `4k` 分辨率，或 `1:1` `2:3` `3:2` 之外的画幅 | `gpt-image-2` `gpt-image-2.5` `gpt-image-2.5-sunburst` | 这三个接受 `resolution`，并支持 15 种画幅 |
| 提交前确定单张价格 | `gpt-image-2-rev` | 按输出分辨率固定计费，与画幅和提示词长度无关 |
| 掩码局部重绘 | `gpt-image-1` `gpt-image-1.5` `gpt-image-2` | 只有这三个接受 `mask_url`；2.5 没有这个参数 |
| 透明背景或输出格式控制 | 五个官方版 | 官方线路都提供这组专有参数 |
| WebP 输出 | `gpt-image-2` `gpt-image-2.5` `gpt-image-2.5-sunburst` | 其余三个模型只输出 `png` 和 `jpeg` |
| 多图参考编辑 | 六个都支持 | `gpt-image-2` 与两个 2.5 最多 16 张，其余三个最多 15 张 |

<Note>
模型之间不会自动切换：`model` 字段决定用哪个模型，参数以该模型的页面为准。
</Note>

## 共同点

以下部分六个模型完全一致：

| 项目 | 取值 |
|---|---|
| 端点 | `POST /v1/tasks`（异步任务，见[任务系统](/cn/docs/task-system)） |
| 动作 | `generate` 文生图 · `edit` 参考图编辑（必须带 `image_urls`） |
| 默认画幅 | `1:1`；可选画幅集合各模型不同，见各模型页 |
| 每次输出 | 1 张 |
| 不支持 | `seed` |

## 统一调用方式

```bash
curl -X POST https://www.qingbo.dev/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "action": "generate",
    "prompt": "一只蓝色陶瓷杯放在白色桌面上，柔和自然光",
    "aspect_ratio": "1:1",
    "n": 1
  }'
```

把 `model` 换成本页任意一个模型 ID 都能直接跑。提交成功后返回 `task_id`。用 [`GET /v1/tasks/{task_id}`](/cn/api-reference/task/status) 查询结果，也可以用 [`Prefer: wait`](/cn/api-reference/task/submit#请求内等待prefer-wait) 在一次调用里等待，或配置 Webhook。
