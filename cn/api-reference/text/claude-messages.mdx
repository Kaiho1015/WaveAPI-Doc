Anthropic 原生 Messages 接口，为已有 Anthropic SDK 的应用保留，GPT-5.6、GPT-6、GPT-6.1 系列与 Responses 专用模型之外的全部文本模型都可调用。除联网搜索（见[文本模型总览 · 计费口径](/cn/api-reference/text/overview#计费口径)）外，本接口不提供 Chat 之外的额外能力，新接入建议直接用[通用对话接口](/cn/api-reference/text/general-chat)。

<RequestExample>
```bash cURL
curl -X POST https://api.qingbo.ai/v1/messages \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "claude-sonnet-5",
    "max_tokens": 1024,
    "system": "你是一个专业的AI助手。",
    "messages": [
      {
        "role": "user",
        "content": "解释一下冒泡排序算法。"
      }
    ]
  }'
```

```python Python
import anthropic

client = anthropic.Anthropic(
    base_url="https://api.qingbo.ai/v1",
    api_key="YOUR_API_KEY"
)

message = client.messages.create(
    model="claude-sonnet-5",
    max_tokens=1024,
    system="你是一个专业的AI助手。",
    messages=[
        {"role": "user", "content": "解释一下冒泡排序算法。"}
    ]
)

print(message.content[0].text)
```

```go Go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "io"
    "net/http"

func main() {
    payload := map[string]interface{}{
        "model":      "claude-sonnet-5",

        "messages": []map[string]string{
            {"role": "user", "content": "解释一下冒泡排序算法。"},
        },
    }

    body, _ := json.Marshal(payload)
    req, _ := http.NewRequest("POST", "https://api.qingbo.ai/v1/messages", bytes.NewBuffer(body))
    req.Header.Set("Authorization", "Bearer YOUR_API_KEY")
    req.Header.Set("Content-Type", "application/json")
    req.Header.Set("anthropic-version", "2023-06-01")

    resp, err := http.DefaultClient.Do(req)
    if err != nil {
        panic(err)
    }
    defer resp.Body.Close()

    result, _ := io.ReadAll(resp.Body)
    fmt.Println(string(result))
}
```

## 鉴权

<ParamField header="x-api-key" type="string">
  API 密钥用于身份验证，与 `Authorization` 二选一

  访问 [API Key 管理页面](https://wave.qingbo.ai/dashboard/keys) 获取您的 API Key

  在请求头中添加：

  ```
  x-api-key: YOUR_API_KEY
  ```
</ParamField>

<ParamField header="Authorization" type="string">
  API 密钥用于身份验证，与 `x-api-key` 二选一

  ```
  Authorization: Bearer YOUR_API_KEY
  ```
</ParamField>

<ParamField header="anthropic-version" type="string" required>
  API 版本号

  指定要使用的 Claude API 版本

  示例：`2023-06-01`
</ParamField>

Anthropic SDK 的 base URL 设为 `https://api.qingbo.ai`，SDK 会自行追加 `/v1/messages`，不需要再补 `/v1`。

## 请求参数

<ParamField body="model" type="string" required>
  模型 ID

  除以下模型外，全部文本模型都可调用本接口：GPT-5.6、GPT-6 与 GPT-6.1 系列（`gpt-5.6-luna`、`gpt-5.6-sol`、`gpt-5.6-terra`、`gpt-6-astra`、`gpt-6-luna`、`gpt-6-sol`、`gpt-6.1-sol`），以及只接受 [Responses 接口](/cn/api-reference/text/openai-multimodal)的 `gpt-5-pro`、`gpt-5.2-pro`、`gpt-5.4-pro`、`gpt-5.3-codex`、`o3-pro`。这些模型发到本接口返回 `400`。

  各模型的缓存档位与支持的能力见[文本模型总览](/cn/api-reference/text/overview)。

  本接口不支持图像输入。
</ParamField>

<ParamField body="messages" type="array" required>
  消息列表，支持交替的 `user` 和 `assistant` 角色

  <Expandable title="消息对象属性">
    <ParamField body="role" type="string" required>
      角色：`user`（用户输入）或 `assistant`（模型回复，用于多轮对话或预填充）
    </ParamField>

    <ParamField body="content" type="string" required>
      消息内容：字符串，或文本内容块数组
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="max_tokens" type="integer" required>
  最大生成 token 数

  生成停止前的最大 token 数量。模型可能会在达到此限制前停止。

  不同模型有不同的最大值，请参考模型文档。

  最小值：1
</ParamField>

<ParamField body="system" type="string | array">
  系统提示词

  系统提示词用于设置 Claude 的角色、个性、目标和指令。

  **字符串格式：**

  ```json
  {
    "system": "你是一位专业的Python编程导师"
  }
  ```

  **结构化格式：**

  ```json
  {
    "system": 
    [
      {
        "type": "text",
        "text": "你是一位专业的Python编程导师"
      }
    ]
  }
  ```
</ParamField>

<ParamField body="temperature" type="number">
  温度参数，范围 0-1

  控制输出的随机性：

  * 低值（如 0.2）：更确定、更保守
  * 高值（如 0.8）：更随机、更有创意

  默认值：1.0
</ParamField>

<ParamField body="top_p" type="number">
  核采样参数，范围 0-1

  使用 nucleus sampling。建议使用 `temperature` 或 `top_p` 其中之一，不要同时使用。

  默认值：1.0
</ParamField>

<ParamField body="top_k" type="integer">
  Top-K 采样

  只从概率最高的 K 个选项中采样，用于移除"长尾"低概率响应。

  建议仅在高级用例中使用。
</ParamField>

<ParamField body="stream" type="boolean">
  是否启用流式输出

  * `true`: 通过服务器发送事件 (SSE) 逐步返回响应
  * `false`: 一次性返回完整响应

  默认值：false
</ParamField>

<ParamField body="stop_sequences" type="array">
  停止序列

  自定义文本序列，遇到时停止生成。最多 4 个序列，每个最长 32 个 token。
</ParamField>

<ParamField body="metadata" type="object">
  元数据

  用于追踪或标识请求的对象。
</ParamField>

## 使用示例

### 单次对话

```json theme={null}
{
  "model": "claude-sonnet-5",
  "max_tokens": 1024,
  "messages": [
    {"role": "user", "content": "解释一下量子计算"}
  ]
}
```

### 多轮对话

```json theme={null}
{
  "model": "claude-sonnet-5",
  "max_tokens": 1024,
  "messages": [
    {"role": "user", "content": "你好"},
    {"role": "assistant", "content": "你好！我是Claude。"},
    {"role": "user", "content": "能解释一下AI吗？"}
  ]
}
```

### 使用系统提示词

```json theme={null}
{
  "model": "claude-sonnet-5",
  "max_tokens": 1024,
  "system": "你是一位经验丰富的数据科学家，专长包括统计分析和机器学习。",
  "messages": [
    {"role": "user", "content": "如何选择合适的机器学习算法？"}
  ]
}
```

### 预填充响应

```json theme={null}
{
  "model": "claude-sonnet-5",
  "max_tokens": 1024,
  "messages": [
    {"role": "user", "content": "列出5个Python最佳实践"},
    {"role": "assistant", "content": "以下是5个Python最佳实践：\n\n1."}
  ]
}
```

## 流式

在同一个 URL 上设置 `stream: true`。依次读取 `message_start`、内容块事件、`message_delta`（携带实际 usage 与 `stop_reason`），最后是 `message_stop`。**`message_start` 里的初始用量不是最终账单**，不能据此计费。

## 用量与计费

原生 `input_tokens` 与 Chat 的 `prompt_tokens` 语义不同：原生的 `input_tokens` **不包含**缓存命中和缓存写入，总输入等于三者相加；`output_tokens` 已包含思考 token。原生响应不带 `usage.cost` 字段，实际扣费到控制台用量记录查询。计费口径见[文本模型总览 · 计费口径](/cn/api-reference/text/overview#计费口径)。

## 当前不支持

- **结构化输出**——Claude 模型不接受 `response_format` 的 `json_schema` 与 `json_object`。
- **工具调用限制**——不支持工具调用的模型（见[文本模型总览](/cn/api-reference/text/overview)「JSON / 工具」列）传 `tools` / `tool_choice`；Fable 系列、`claude-opus-5-5` 与 `claude-sonnet-5-5` 的 `tool_choice` 取 `any` 或 `tool`（只接受 `auto`）。
- **图像输入**。

以上请求返回 `400`，不计费。显式缓存在本接口可用：把要复用的长前缀放进 `system` 数组，写法与命中条件见[文本模型总览 · 缓存](/cn/api-reference/text/overview#缓存)。
